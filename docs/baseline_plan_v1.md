# IronFlow Baseline v1 运行说明

## 目的

Baseline v1 只衡量短周期预测的开发集表现，不生成比赛提交文件，也不打开封存留出集。它回答三个问题：当前值延续有多强、前一天同期有多强，以及一个参数固定的轻量树模型能否稳定超过朴素基线。

## 冻结切分

- `dev_01`：训练数据截至 2025-01-31 23:45，验证起点为 2025-02-01 至 2025-02-02，共 192 个滚动起点。
- `dev_02`：训练数据截至 2025-02-28 23:45，验证起点为 2025-03-01 至 2025-03-02，共 192 个滚动起点。
- `dev_03`：训练数据截至 2025-03-31 23:45，验证起点为 2025-04-01 至 2025-04-02，共 192 个滚动起点。
- `holdout_01`：2025-04-29 00:00 至 2025-04-30 22:00，共 185 个起点。本轮禁止计算其预测和指标；最后一个起点的 120 分钟目标恰好落在 2025-05-01 00:00。

每个开发折使用扩展训练窗。任一目标步长的训练样本都必须保证标签时间不晚于该折训练截止时间。

## 三组基线

1. `persistence`：全部步长均预测为起点时刻最新可见发电量。
2. `seasonal_day`：用目标时刻前 96 个采样点（前一天同期）作为预测。
3. `lightgbm_direct`：每个折、每个目标、每个步长各训练一个模型，共 48 个模型；不使用验证折早停。

LightGBM 固定参数：L1 回归目标、300 棵树、学习率 0.03、31 个叶节点、叶节点最少 50 个样本、行列采样比例均为 0.8、L2 正则 1.0、随机种子 42。输入使用已经审计的起点时刻字段、两个目标的历史滞后项（1/4/8/16/32/96/192/672 步）和周期时间特征。

## 指标与产物

主开发指标为 MAPE，同时记录 `1-MAPE`、MAE、RMSE。当前目标没有零值；脚本仍明确采用“零实际值不进入 MAPE 并单独计数”的诊断规则，不能据此假定官方隐藏评分实现完全相同。

每次运行创建不可覆盖的 `outputs/baseline_runs/<run_id>/`，保存逐点验证预测、分层指标、训练摘要、特征重要性、解析后的配置和运行清单。运行清单记录 Git 状态、配置与数据指纹、依赖版本和运行时长。该目录属于本地产物，不提交公开仓库。

每轮成功完成后还会向本地 `experiments/registry.csv` 追加一行索引，便于后续比较实验；该注册表同样不会上传公开仓库。
