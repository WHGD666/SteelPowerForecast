# IronFlow 工业业务逻辑 v0

## 业务链路

```text
高炉/焦炉/转炉煤气发生
        ↓
热风炉、生产用户、混气用户优先消耗
        ↓
气柜库存与管网压力缓冲
        ↓
剩余煤气及可发电资源
        ↓
机组启停、负荷分配和三类煤气消耗
        ↓
generator_1、generator_all
        ↓
外购电量、最大需量和经济收益
```

## 变量角色

- 资源输入：煤气发生量、进混气站流量、用户消耗量。
- 状态变量：气柜库存、库存变化方向、隐含机组启停状态。
- 历史观测：发电负荷和发电耗气量。
- 预测目标：`generator_1`、`generator_all`。
- 后续控制量：`opt_generator_use_blast_furnace_gas`、`opt_generator_use_coke_gas`、`opt_generator_use_converter_gas`、机组负荷和启停。

## 平衡关系草案

理论上可表达为：

```text
煤气发生 - 优先用户消耗 - 发电耗气 - 放散
= 气柜库存变化
```

当前字段不完整，存在整列为空、未观测用户和单位未确认问题。因此该关系只能作为待校准的软约束或诊断残差，不能直接作为硬等式写入优化模型。

## 调度优先级

1. 保证生产用户供气。
2. 保证气柜处于安全区间。
3. 避免煤气放散。
4. 在机组容量、最小稳定负荷和爬坡约束下分配负荷。
5. 在高价时段提高自发电经济价值，减少不必要的低价时段发电。
