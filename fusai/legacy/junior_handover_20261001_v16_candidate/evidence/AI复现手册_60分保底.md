# AI 复现手册：煤气发电量预测（2026AIC 复赛）

> **给下一个 AI 的使用说明（务必先读本节，比配方更重要）**
>
> 1. **本手册的结论全部是"假设"，不是"定律"。** 它们来自 16 次真实提交的官方读数和封存留出集实验，但样本有限、且只在"2025 年 10 月这个测试期"上验证过。置信度标注见 §4：[实测×多次] > [实测×1 次] > [机理推测]。
> 2. **真正的资产是方法，不是结论**：单变量改动 → 官方分目标明细当读数 → 只叠加被验证的增益。照抄结论的 AI 会停在 60.57；会用方法的 AI 才能超过它。
> 3. **60.5717 是地板，不是天花板。** §3 的五步配方是"保底复现"，跑通后你的首要任务是**打败它**，不是复现它。榜单上还有 65~70 分的队伍，说明有我们没找到的东西。
> 4. **"已证伪"要重读**：每个失败实验只证伪了**我们那个具体设计**（死因分析见 §5）。换实现、换参数、换数据窗口后重试，完全可能翻盘。
> 5. **合规是生存条件**：可复现成绩 <60 分直接取消资格；使用未来数据直接作废。§6 的红线逐条自查。

## 0. 任务一页纸

- **赛题**：钢铁企业煤气自发电量滚动预测。两个目标：`generator_1`（4×50MW 小机组合计）、`generator_all`（6 机组总量，4×50+2×120MW）。
- **训练数据**：2025-05-03 ~ 2025-09-30，原始 **1 分钟**粒度，4 张表（煤气产量/煤气用户/气柜/发电负荷）。
- **测试期**：2025-10-01 ~ 2025-10-10。**测试集的目标列（generator_1/generator_all）全部为空**——测试期没有任何电量真实值；但煤气流量、气柜、发电耗气等**协变量**在测试文件里全天候提供（1 分钟）。
- **预测**：起点每 15 分钟一个（共 **960 个**），从 t 滚动预测 t+15 ... t+1440 分钟（96 步 = 24 小时）+ 短期 8 步（t+15..t+120）。
- **提交**：zip 内只放两个文件（**不放 input.csv**）：
  - `s_result.csv`：960 行 × 17 列（datetime + generator_1 的 8 步 + generator_all 的 8 步）
  - `l_result.csv`：960 行 × 193 列（datetime + 两目标各 96 步）
  - zip 名：`这模型调的有力量_gas_predict_semi.zip`
- **评分**：满分 100 = 短期 50 + 长期 50；指标 1-MAPE（实际值 = **15 分钟区间均值**）；及格线短期 90% / 长期 85%；`anomaly=normal` 表示无审查处罚。
- **已验证地板**：按 §3 五步 = **60.5717 分**（官方返回）。

## 2. 评分机制（我们用 16 次提交反推出的情报）

- **置信度说明**：[实测×多次] = 两个以上提交独立验证；[实测×1] = 单次读数；[推测] = 机理推断未验证。
- 满分 100 = 短期 50 + 长期 50；每文件的分数 = 官方明细里的 `score`，明细同时返回 `accuracy` 和分目标（g_1、g_all）准确率。**[实测×多次]**
- 总体 accuracy = 两目标准确率的算术平均。[实测]
- 评分对准确率是**凸映射**：实测局部斜率短期 ≈1.5 分/点、长期 ≈3.0 分/点（80~91% 区间）。[实测×多次] 更高处斜率未知（榜单最高 79，说明高处还有空间）。
- 实际值口径 = **15 分钟区间均值**（官方原话），且**评分网格 = 960 个 15 分钟起点**（14400 行提交与 960 行同分，实测）。[实测×多次]
- 官方明细按目标分列 → **一次提交能同时读出两个独立实验的效果**（只要改动分别落在 g1 和 gall 上）。[实测×多次] —— 这是迭代效率的根基。
- `anomaly` 字段 = 统计审查结果；我们所有提交均 `normal`，未观察到审查扣分。[实测×多次]
- 每天最多 5 次提交；**排行榜取最高分**；提交成功 ≠ 立即出分（几分钟到 1 小时+）；"未提交"通常是参赛作品名称没填。

## 3. 五步复现流程（60.5717 保底）

### 第 1 步：因果清洗

```powershell
cd <repo>
python src/prepare_dataset.py --config configs/cleaning_v2.yaml
```
- 1 分钟 → 15 分钟整点网格（取整点瞬时值）→ 协变量因果前向填充（limit=4）→ `feat_*` 标志。
- 验证：`outputs/prepared_v2/` 下 `train_prepared.csv` **14,496×55**、`test_prepared.csv` **960×55**、`input.csv` 960×25；打印 PASS。

### 第 2 步：v2 基线包（≈48.9 分）

```powershell
python src/build_submission_semi.py --mode build --submission-id <目录名>
```
- 192 个 LightGBM（每目标×每步长；L1、300 树、lr 0.03、31 叶、deterministic、seed 42）训练 + 预测 + 双文件打包，内含 validate_submission 门禁。
- 验证：打印 PASS。**此版本提交 ≈48.9（实测）。**

### 第 3 步：复现链验证

```powershell
python src/build_submission_semi_variants.py --variant v9 --verify
```
- 验证：输出 `s_result.csv: IDENTICAL`、`l_result.csv: IDENTICAL`（对官方 52.4085 那版逐字节一致）。

### 第 4 步：60.57 主配方（v15 脚本 = 后处理配方全集）

```powershell
python src/build_submission_semi_v15_sepwindow.py
```
- 在 v2 基线预测上做两层后处理（全部只用 ≤t 信息）：
  1. **g1 燃料混合**：`g1 = 0.2×树模型 + 0.8×燃料反推`。燃料反推 = 3 个发电耗气列对 g1 的线性回归，**拟合窗口仅 2025-09-01~09-30**；
  2. **长期 gall 远段自适应**：步长 >32 的 gall 列 = `0.60×(0.75×原预测 + 0.25×训练期(星期,小时)气候均值) + 0.40×燃料反推 gall`（`use_bfg + use_converter` 两列回归，9 月窗口）。步长 1~32 不动。
- 验证：zip 939,113 字节；**提交 = 60.5717**（short 91.09% [g1 89.14, gall 93.04]；long 84.47% [g1 82.49, gall 86.44]）。

### 第 5 步：自检提交

对照 zip 大小/SHA256 → 上传 → 明细抄回 `manifests/official_submissions.csv` → 按明细设计下一发。

## 6. 合规红线（违反 = 作废，逐条自查）

1. 预测起点 t 的特征**只能用 ≤t 的观测**。测试文件里 t 之后任何时刻的字段（耗气/气柜/产量/目标）**读取即作弊**——包括用它们算的滚动均值、差分、占比、占比衍生特征；
2. 合法示例（全部已用）：起点 t 当期的 `generator_use_*` ✓；"昨天同一时刻"的协变量（≤t）✓；训练期日历气候均值 ✓；**预测**出的未来路径（不读真值，官方原话允许"自行预测次日气量"）✓；
3. 训练期日历统计特征合法；未来日历不可用；
4. 封存留出集（9/28-29）只在候选冻结前用一次；
5. 推理分钟级完成（30 分钟业务约束远离我们）；训练时长无限制；
6. 最终代码提交：`requirements.txt` + `python -u xxx.py` + 入口 `predict from models.py`——**提交前把所有一次性构建逻辑固化成脚本**（我们已固化 v9/v11/v12 并验证逐字节 IDENTICAL，v13-v16 同样处理）。

## 7. 冲高路线（60 → 65 → 70）

官方口径：正常 60~65，65~70 高分段，70 = 顶尖；国赛线约 64。**冲高的正确姿势：每发提交前先做本地诊断，每次明细回来先更新本手册的置信度标注。**

排队中的假设（按期望值排序）：
1. **树模型近期化**（已构建：`--train-start 2025-09-01` + v15 配方）：燃料窗口的近期化梯度（+3.9、+3.0）提示树模型同向的可能；风险是 2,900 行数据可能饿死树模型——读数会告诉你；
2. **燃料窗口继续扫**（9 月上半月/下半月）：梯度可能未到头；
3. **远段自适应权重扫描**（40%→55%）与**短段也加自适应**：+0.62 的边际未测；
4. **日级分层**：先预测"明天日均水平"（日级噪声小）再叠日内形状——远段 gall（86.44 vs 留出集 91.3）的最后一块拼图；
5. **测试期的两个"台阶"**：10-02 爬坡（+27 MW/日）、10-10 崩塌（−85 MW/日）——任何能感知日级水平突变的方法都是大分。**这是我们认为 65→70 的钥匙，但没有已验证的实现。**
