# IronFlow 任务合同 v2（复赛长周期）

> 状态：**待官方确认复赛口径后冻结**。本文件为复赛新增，`docs/task_contract_v1.md` 初赛短周期契约冻结不动、逐字节保留。

## 1. 预测任务

- 预测对象：`generator_1`、`generator_all`。
- 数据粒度：**原始数据为 1 分钟级**（已核实 `Semi_*.csv` 实际采样间隔）；预测口径按 15 分钟滚动（`frequency_minutes: 15`）。
- 预测方式：滚动预测。起点每 15 分钟前进一次，最终一次性提交覆盖整个测试期的结果宽表。
- **复赛长周期**：从起点 `t` 预测 `t+15` 至 `t+1440`，共 **96 步**（24 小时）。
- 评价主指标：官方 `1-MAPE`。零值、缺失和多目标聚合的底层规则尚未公开。

## 2. 起点可见信息集

对于每个预测起点 `t`，模型只能使用在该时刻已经可获得的信息：

允许：

- 四类原始表中时间戳 `<= t` 的观测；
- `t` 行已提供的当前实际发电量，包括 `generator_1`、`generator_all`（若该行存在）；
- 已知的日历特征、电价时段信息和其他不依赖未来观测的外生信息；
- 之前滚动起点已经输出的预测值。

禁止：

- 任何时间戳 `> t` 的观测、目标、发电耗气或用户消耗；
- 使用测试期完整标签反推特征、阈值、异常处理规则或模型参数；
- 外部数据、外部预训练权重、联网推理服务和人工逐条修正测试结果。

**长周期强化说明**：

- 96 步跨度下，proxy-sensitive 字段（`generator_use_blast_furnace_gas`、`generator_use_coke_gas`、`generator_use_converter_gas`）的未来值禁用约束更易被违反，必须逐 horizon 复检。
- 因果前向填充 `limit_steps <= 4` 冻结约束不变，不得以长周期为理由放宽。
- 复赛原始数据与预测口径之间存在"1 分钟原始 → 15 分钟预测"的重采样问题，官方步长定义待确认。

## 3. 特征命名与敏感字段

- 原始字段名必须保持赛事要求的英文名称。
- 新特征必须使用 `feat_` 前缀，否则不能通过特征工程检查。
- `datetime` 是滚动起点键，不直接作为普通连续数值输入。
- `generator_use_blast_furnace_gas`、`generator_use_coke_gas`、`generator_use_converter_gas` 与目标存在业务近因关系，标记为 proxy-sensitive。当前时刻值可用不代表未来值可用。
- 全空字段保留在审计中，但第一版候选特征排除；非全空缺失只能按历史可用信息或折内规则处理。

## 4. 复赛提交契约

提交压缩包命名：`teamname_gas_predict_semi.zip`（待官方确认）。

`input.csv`：

- UTF-8 编码；
- 包含 `datetime`、原始特征和可选的 `feat_` 特征；
- 原始特征名不得改写；
- 预测起点按测试期滚动时间完整覆盖。

`s_result.csv`（复赛长周期）：

- UTF-8 编码；
- 列顺序固定为 `datetime`，随后是 `generator_1` 的 96 个偏移列，再是 `generator_all` 的 96 个偏移列；
- 列名固定为 `generator_{target}_t+{offset}_pred`（offset 取值 15, 30, ..., 1440）；
- `datetime` 表示预测起点，不是目标时刻；
- 起点不得缺失、重复或错位；预测列为浮点数，至少保留 3 位小数；
- 即使末端目标超出公开数据范围，也必须按起点完整输出。

## 5. 验证门禁

在模型训练前必须由自动检查证明：

1. 任何验证起点的输入只含 `<= t` 信息；
2. 目标列只在对应未来偏移用于评分；
3. `input.csv` 额外字段全部以 `feat_` 开头；
4. `s_result.csv` 列名、起点集合、顺序、缺失和重复检查全部通过；
5. 缺失、异常、边界上下文和 proxy-sensitive 字段有可复现记录。

## 6. 冻结纪律（v2 继承并强化）

本契约完整继承初赛七项冻结纪律，并针对 96 步长周期强化说明：

1. **时间因果性**：预测起点 `t` 仅可使用 `<= t` 的信息；禁止任何 `> t` 的观测、目标、耗气或用户消耗。
2. **proxy-sensitive 三字段未来值禁用**：`generator_use_blast_furnace_gas`、`generator_use_coke_gas`、`generator_use_converter_gas` 当前时刻值可用，未来值禁用。
3. **特征命名**：所有新特征必须使用 `feat_` 前缀。
4. **因果前向填充**：仅允许向后看，`limit_steps <= 4`。
5. **封存留出集**：`holdout_01` 全程封存，候选冻结前不得消费。
6. **切分指纹不变**：初赛冻结指纹为 `14c74090...`；复赛长周期必然产生新指纹（当前 `1e890747...`），两者不得混用比较。
7. **失败实验也留痕**：失败 run 必须保留 `failure.json` 与 registry 失败行，不得删除或覆盖。
8. **run_id 不可覆盖**：一旦创建的 run_id 不得复用或覆盖。
