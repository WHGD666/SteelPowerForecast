# short-g1 因果专家门控协议

## 假设

固定 ±5 MW 动态专家总体和所有 horizon 均提升，但在最后近期折略退化。与其继续修改底层预测，建立一个低容量门控，仅用预测起点可见的过程状态和 v16/动态专家分歧判断动态专家的可信度。

## 严格时间协议

- 验证 wf04：门控只训练 wf03 的 OOF 专家胜负；
- 验证 wf05：门控只训练 wf03+wf04；
- 禁止用 wf05 反向训练 wf04；
- 每个起点的训练标签是 8 个 short horizon 平均 MAPE 下动态专家是否严格优于 v16；
- 推理时不使用目标或该标签，只使用起点及历史过程特征和两专家预测分歧。

## 固定模型与输出

20 个特征：8 个专家分歧/形状统计，加三类发电耗气与 holder_2 的 current、lag60、roll1440。中位数填补、标准化和 L2 logistic 全部在更早折拟合，C=0.1、balanced class weight。输出概率 `p`，最终预测为：

`v16 + p × (capped_dynamic - v16)`

不搜索阈值，不做 hard gate，不调整底层 70/30 或 ±5 MW 配方。

## 晋级门禁

- 仅在顺序验证 wf04+wf05 上评估；
- pooled short-g1 至少 +0.50 pct；
- 两折、8 个 horizon 和普通工况全部不得退化；
- 至少两个事件且半数改善；
- 门控 ROC-AUC 至少 0.55；
- 通过也不自动生成提交，先审查全量拟合合同。
