# 动态燃料平台探针复盘与后续冲分裁决

## 1. 结论

全时段 horizon-specific dynamic-fuel 替换路线正式关闭。当前唯一官方控制仍是 v29b / 63.4621；
不得把 62.8070 探针或 56 天版本继续做窗口、融合权重和小数点级平台搜索。

## 2. 平台证据

- submission：`20261004T153207_dynamic_fuel_probe_v1_98feef8d8a`
- ZIP SHA-256：`9c5e7fb36cac5f53db2053198f5180f926ccdbed7745d507979e887f34a5f1de`
- 唯一变化：long `generator_1 = 0.70 × dynamic_fuel_ols + 0.30 × v3_baseline_long_g1`
- 冻结区块：v29b short 文件字节级一致；long `generator_all` 逐值一致
- 官方总分：62.8070
- v29b 控制：63.4621
- 差值：-0.6551

平台没有返回分项目标，因此不能反推 long-g1 的官方准确率。由于其他三个区块冻结，可以确认的
最小结论是：这次 long-g1 整体替换在十月测试期有害。

## 3. 本地证据为何失真

21 天版本的 pooled OOF 提升 3.3675 pct，但收益高度集中在 July、late September、holder1-active
和已知事件样本；August、BF3-active 与普通工况均退化。十月特征中心又更接近退化的 BF3-active 折。
因此 pooled OOF 把少量大收益事件与大量普通工况混在一起，给出了不可靠的总体乐观读数。

56 天版本没有修复这一问题：

| 项目 | 结果 |
|---|---:|
| blend 总体准确率增益 | +0.3083 pct |
| standalone dynamic OLS | -0.3767 pct |
| 普通工况 | -5.7747 pct |
| 最近三折均值 | -1.5309 pct |
| 最近最差折 | -6.9628 pct |
| 改善 episode 比例 | 2/4 |

这说明问题不是 21 天窗口太短，而是动态燃料关系本身具有明显工况依赖性。

## 4. 不再继续的变体

- 把动态燃料权重从 0.70 改成 0.25、0.50 或其他值；
- 再搜索 28/42/70/90 天窗口；
- 仅在平台上根据总分做权重插值；
- 将同一动态模型扩展到 `generator_all`；
- 使用事后 episode 标签为测试预测开关。

这些做法要么违反预登记停止条件，要么无法解决跨工况方向相反的问题。

## 5. 下一步优先级

### P1：隔离 g1 异常日样本加权

保留 v29b/v28 的字段、树窗口、燃料回归和近远权重，只改变 g1 树的训练样本权重。历史证据显示
×3 在三折均为正（约 +0.05 至 +0.33 pct），但 v34b 同时改变了燃料权重，官方退化不能归因到加权。
这是尚未被干净验证、风险最低的下一项实验。它更像小幅加固，单独达到 65 的概率不高。

### P2：因果事件 hazard

预测每个 origin/horizon 是否将进入低燃料或发电台阶事件，只在高置信区域对 v29b 做有限校正。
输入只能来自 origin 及历史过程量，加上已知未来日历；训练和验证按完整 episode 留出，不能随机拆分事件。
这是目前唯一可能一次覆盖主要误差日、提供 1 分以上增益的方向，但样本只有 13 个 episode，必须强正则、低容量并报告事件外退化。

### P3：三个小增益补充线

1. 目标时刻电价与距峰谷切换时间：合规已知未来日历，预期小但稳定。
2. short-g1 恢复列：历史上未被单独隔离，可能贡献小幅短周期收益。
3. gall 结构多样性：不同 `min_child_samples` 或 bootstrap，而不是已经失败的多随机种子平均。

## 6. 提交门禁

新候选必须在冻结验证上达到：主区块至少 +0.8 pct、普通工况退化不超过 0.2 pct、最近单折无明显负值、
多数独立 episode 同向改善、near 预测不劣化。一次只替换一个周期×目标区块，其余 v29b 内容逐值冻结。
