# 学弟旧实验与历史证据

## 1. 定位

学弟资料是重要的研究证据和失败经验，但不是 v3 可直接执行的代码基线。

使用原则：

- 原始资料保持只读。
- 不在旧脚本上继续打补丁。
- 新代码不得直接依赖旧输出目录。
- 有价值组件必须经过审查、测试后迁入 `src/common/`。
- 历史平台结果与新 v3 本地结果分开记录。

## 4. 不能直接继承的内容

- 15 分钟整点抽样而非区间均值。
- 错误 horizon 标签偏移。
- `blast_furnace_3`、`air_heater_3`、一号气柜被错误视为全空。
- 旧煤气平衡遗漏部分热风炉。
- 旧 holdout 已经被反复选择。
- 1 分钟广播脚本第二目标列块索引错误。
- 递归正式推理开头滚动状态未装入训练历史。
- `holdout_calibration` 中 g1 点值实际引用了错误 target series。
- v10 使用真实未来路径的提升仅是 oracle 上界。

## 5. 复现缺口

当前资料未形成 v9 的完整证据链：

- 所提供 `build_submission_semi.py` 未包含 v9 燃料混合生成逻辑。
- v9 提交文件和 manifest 未随资料提供。
- `official_submissions.csv` 未登记 v8/v9。
- v10 代码硬编码依赖缺失的 v2/v9 输出目录。
- tau 检查原始 JSON 未包含在交付包中。

因此：

```text
historical_official_best: 52.4085
reproducibility_status: incomplete
v3_baseline_eligible: false
```

## 6. 值得迁移的思想

- LightGBM L1 作为低成本基线。
- 物理煤气供需和气柜动态特征。
- g1 的燃料耗气机理回归。
- 对未来煤气路径进行预测再估计发电量。
- 单变量平台提交和分目标观察。

迁移顺序必须是：先修正标签和验证，再重新证明这些思想的增益。
