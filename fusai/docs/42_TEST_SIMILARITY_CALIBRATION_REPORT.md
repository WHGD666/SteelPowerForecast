# 十月测试相似度验证校准报告

## 1. 结论

固定的 process-only 域分类器能够清楚区分训练起点与十月测试起点，但由此得到的相似度权重
**不能解释三次已知平台结果**。校准门禁失败，本口径不得用于模型选择，也不继续调域模型、特征、
裁剪阈值或 top-k 比例。

正式 run：`20261004T145819Z_test_similarity_d7b3a8efa8`。

## 2. 冻结设置

- 训练起点 14,496，测试起点 960；
- 158 个因果过程特征，仅含 current、60 分钟均值、720 分钟均值和 current-state indicator；
- 排除目标历史、全部 calendar 和任何起点之后的观测；最大来源时间偏移为 0；
- 标准化逻辑回归，按自然日分组五折；
- 权重为测试域概率 odds，折内归一并固定裁剪到 0.25–4.0；
- 三个线上探针及其 OOF 文件哈希在运行前冻结。

## 3. 结果

域分类 grouped-CV AUC 为 **0.951865**，说明十月过程状态与历史训练分布差异显著。最小有效样本比例为
**0.732631**，样本退化门禁通过。

| 平台探针 | 未加权 OOF 增益 pct | 相似度加权增益 pct | top 25% 增益 pct | 官方总分差 | 应识别方向 | 是否识别 |
|---|---:|---:|---:|---:|---|---|
| dynamic fuel long-g1 | +4.0814 | +3.9937 | +3.4745 | -0.6551 | 负 | 否 |
| shared long-g1 | +0.6336 | +0.6566 | +0.2882 | -0.3577 | 负 | 否 |
| shared long-gall | +0.3911 | +0.4072 | +0.3732 | -0.0082 | 中性 | 否 |

三个方向全部判错，因此 `calibration_gate_passed=False`。

## 4. 解释

域分类器识别到的是“十月与历史不同”，但这种全局工况距离没有定位候选模型的误差机制。晚九月验证起点在
最终域模型下的测试概率几乎为零，而 holder1-active 折虽然相对更接近测试，三个候选在该折仍表现为正。
这说明平台退化更可能来自未观测的未来事件、候选配方对十月特定日期的系统偏差，或 legacy OOF 与最终提交
全量拟合之间的结构差异；不能用一个全局密度比解决。

## 5. 决策

1. 拒绝 test-similarity 加权 OOF 作为晋级指标；
2. 不对域分类器、概率裁剪或 top-k 做事后调参；
3. 不生成提交包，不消耗平台次数；
4. 下一项实验回到评分目标本身：在 v28 long-g1 血统中，只把树模型训练损失从 MAE 对齐到官方 MAPE，
   其余标签、特征、窗口、燃料回归和融合权重全部冻结。
