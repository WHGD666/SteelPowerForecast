# 十月测试相似度验证校准协议

## 目的

动态燃料、shared g1、shared gall 均在近期 OOF 为正，但官方平台分别为 -0.6551、-0.3577、
-0.0082 分。这说明当前 OOF 无法代表十月测试工况。本诊断不训练预测模型，只使用无标签测试过程量
评估每个历史起点与十月的工况相似度。

## 冻结方法

- 特征：current、rolling 60m mean、rolling 720m mean、current-state indicator；
- 排除全部 calendar 特征和目标历史；最大来源偏移为 0；
- 域模型：标准化逻辑回归，按自然日分组五折评估；
- 权重：测试概率 odds，每个验证折归一，固定裁剪 0.25–4.0；
- 不根据结果更换模型、特征或裁剪阈值。

## 成功条件

加权 OOF 必须同时识别：

1. dynamic fuel g1 为负；
2. shared g1 为负；
3. shared gall 为中性（绝对增益不超过 0.15 pct）；
4. 每折有效样本比例不低于 30%。

任一失败则该验证口径不得用于选择模型。只有全部通过，才允许据此训练 test-similarity 加权的新候选。
