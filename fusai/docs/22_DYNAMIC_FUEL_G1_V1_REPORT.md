## 6. 为什么当前不提交

1. `promotion_passed=[]`，普通工况与近期最差单折两个预登记门禁同时失败。
2. 当前控制是 baseline v1，而平台控制 v29b 没有 OOF；`+3.3675 pct` 不能直接外推到 v29b。
3. 全量训练时 21 天窗口将集中在 2025-09-10 至 2025-09-30，和历史上触发 `cheat_detected` 的过窄九月燃料窗口存在风险相似性。触发机制不是官方公开规则，因此这里只能记录为风险，不能断言必然触发。
4. 直接把动态结果与 v29b long-g1 做 70/30 融合，和本轮“动态结果与 baseline control 做 70/30 融合”并非同一个被验证模型。
5. 平台虽然每天允许多次提交，但失败实验不应绕过已冻结的安全门禁。
