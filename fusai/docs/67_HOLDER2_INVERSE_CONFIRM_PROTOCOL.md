# holder_2 反向边界信号新鲜块确认协议

## 1. 实验定位与必要性

D-078 的预登记正向假设在四个开发块上一致判负，但同一诊断暴露了方向相反、4/4 块
一致的反向关联（高压起点 → 控制远端高估）。按项目纪律（D-059 先例：不得事后取反、
不得在开发块上验证事后假设），该反向信号**尚未被证明**，必须先通过新鲜块确认。

本轮是 **diagnostic**：在四个从未参与任何分析的新鲜十日块上重建冻结的 shared-horizon
tree 控制，并对重建残差应用预先冻结的反向门禁。不训练修正模型，不生成提交。

## 2. 新鲜块选择（冻结）

数据范围 2025-05-03 → 2025-09-30；折内边界历史 ≥30 天的约束排除 5 月；9 月已被两个
开发块（09-03~09-12、09-19~09-28）占用且 09-13~09-18 不足十日。最终四个新鲜块：

| fold_id | 验证窗口 | 折内历史 | 与开发块的关系 |
|---|---|---:|---|
| fresh_01_june_a | 2025-06-11 ~ 06-20 | 39 天 | 全新月份，从未使用 |
| fresh_02_june_b | 2025-06-21 ~ 06-30 | 49 天 | 全新月份，从未使用 |
| fresh_03_july_late | 2025-07-18 ~ 07-27 | 76 天 | 与 7 月开发块隔 8 天，日期不重叠 |
| fresh_04_august_late | 2025-08-21 ~ 08-30 | 110 天 | 与 8 月开发块隔 11 天，日期不重叠 |

代码强制断言：新鲜块互不重叠、与全部四个开发块（07-01~07-10、08-01~08-10、
09-03~09-12、09-19~09-28）不重叠、每块 960 个连续 15 分钟起点。已知不完整区间

## 3. 控制组重建（与已封存配方逐项一致）

每个新鲜块独立重建 shared-horizon tree 控制，一切超参照抄 run
`20261005T080116Z_analog_trajectory_g1_4e4f828951` 的冻结配置，不得改动：

- 树特征：21 个预登记因果过程列（与 analog 实验相同清单）；
- 库起点：块开始前 1440 分钟为止、60 分钟步距、96 步轨迹完整的 origin；
- 训练目标：`generator_1` 官方 15 分钟区间均值，`build_prediction_long` 同一展开；
- LightGBM：regression_l1、300 树、lr 0.03、leaves 31、min_child 50、subsample 0.8、
  colsample 0.8、reg_lambda 1.0、seed 20261005、deterministic、样本权重
  inverse_absolute_target（floor 1.0）；
- 结果变量：与 D-078 完全同口径的 near/far 有符号百分比残差与远-近真实变化比。

新鲜块控制组无平台对照，其绝对精度只作 fit_summary 参考；门禁只依赖残差结构。

## 4. 反向门禁（在看到任何新鲜块结果之前冻结）

全部满足才允许预登记后续修正模型实验：

| 条件 | 阈值 |
|---|---|
| pooled Spearman(压力, 远端残差) | ≤ **-0.08** |
| 远端残差 Spearman 为负的块比例 | ≥ 75% |
| pooled 高压组−低压组远端残差差 | ≤ **-1.0 pct** |
| 该差值为负的块比例 | ≥ 75% |
| pooled Spearman(压力, 远-近真实变化比) | ≤ **-0.05** |
| 机制（真实轨迹）Spearman 为负的块比例 | ≥ 75% |
| 每块高/低压组覆盖率 | ≥ 5% |

- 残差类阈值是 D-078 原门禁的逐项符号翻转，未按开发数据重新调校；
- 新增机制条件的依据：开发块上该关系最强（pooled -0.29，分块 -0.11~-0.47 全负），
  且只依赖真实负荷，不依赖控制树质量，可抵御"控制较弱导致伪残差相关"的质疑；
- 已知不对称性：6 月块控制训练数据较少（约 60-90 库起点/天 × 96），残差噪声更大，
  这会使 Spearman 向零衰减（偏保守，不会造成假通过）；但残差 spread 可能整体放大，
  由机制条件与块比例条件共同兜底；
- 任何一条不满足：holder_2 边界路线（含反向）**永久关闭**，不回扫阈值、不加块、
  不换分桶；
- 即使全部通过，本轮也不生成提交；下一步须另行预登记固定形状、固定幅度、仅作用
  于高压组远端 horizon 的修正实验，并继续用这四个新鲜块作开发验证。
