# 国庆目标时刻 long-g1 保守燃料修正候选

## 唯一变化

以 v29b 63.4621 为控制，只在 long `generator_1` 且目标区间起点落于 2025-10-01 至 2025-10-08 时，
将 v28 的九月 OLS fuel component 乘固定 0.95：

`candidate = v29b_long_g1 + fuel_weight(h) × (0.95 - 1) × september_ols_fuel(origin)`

其中 15/30 分钟 `fuel_weight=0.8`，其余 horizon 为 0.6。short 整个文件、long `generator_all`、
非假日 long-g1 全部冻结。修正幅度来自跨块诊断中较保守的端午 scale 0.951977 的预先四舍五入，
禁止平台出分后扫描 0.94/0.96 等邻域。

## 风险与验收

- 训练证据只有劳动节尾段与端午节两个块；
- 国庆钢铁生产行为可能不同于前两个节假日；
- 必须检查目标时刻边界、near/far 改变量、物理约束和冻结区块逐值一致；
- 只生成候选，不自动上传；平台若不高于 63.4621，节假日修正路线立即关闭。
