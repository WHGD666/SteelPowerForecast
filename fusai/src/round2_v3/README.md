# 复赛 v3 正式代码区

未来代码按职责拆分，不使用单个超大脚本同时完成清洗、训练、推理和打包。

计划模块：

- 数据审计。
- 正确区间标签构建。
- 因果特征构建。
- walk-forward 切分与验证。
- baseline 与实验模型。
- 短期/长期滚动推理。
- 物理一致性检查。
- 提交包构建。

当前已有原始数据审计、标签构建、切分物化和本地指标模块；它们均不训练模型。

它只评估冻结的 5 个 model-selection 折，不读取 Sep 28–29 消费开发折，也不生成提交文件。
